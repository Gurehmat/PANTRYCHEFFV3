# PantryChef

PantryChef is a comprehensive recipe management web application designed to help you make the most of what's in your pantry.

## Live Demo
Check out the live application here: [https://gurehmat.github.io/PANTRYCHEFFV3/#/](https://gurehmat.github.io/PANTRYCHEFFV3/#/)

## Features
- **Smart Pantry Management**: Keep track of your ingredients.
- **Recipe Matching**: Find recipes you can cook right now based on your inventory.
- **AI-Powered Substitutions**: Use Gemini AI to find ingredient substitutes when you're missing something.
- **Shopping List**: Automatically generate shopping lists for missing ingredients.
- **Favorites**: Save your favorite recipes for quick access.

## Tech Stack
- **Frontend**: React, Vite, React Router
- **Backend/Database**: Supabase
- **AI**: Gemini AI (for scanning and substitutions)
- **Styling**: Tailwind CSS
